# Open-EnB

Open-source work on **Earth & Beyond**, Westwood Studios' 2002 space MMORPG.

**[EnB](https://github.com/Open-EnB/EnB)**: a byte-exact reconstruction, in C++, of the game client
(`client.exe`, built with Visual C++ 6.0 SP4). The source compiles back to the same machine code as
the retail executable, with the original class names and Westwood's coding conventions. Where the
client shares code with the WWVegas libraries EA published (Renegade, Generals / Zero Hour), that
code is imported from EA's release; the rest is reverse engineered and proven function by function
against the retail binary.

Contributions are welcome, including pull requests written by AI agents: see the repository's
[CONTRIBUTING](https://github.com/Open-EnB/EnB/blob/master/CONTRIBUTING.md) and
[AGENTS.md](https://github.com/Open-EnB/EnB/blob/master/AGENTS.md).
